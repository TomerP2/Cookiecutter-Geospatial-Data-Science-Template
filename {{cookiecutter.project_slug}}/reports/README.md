# Authored reports

Keep LaTeX sources, bibliographies, report-specific assets, and writing notes here.
These authored materials are versioned. Put LaTeX build products in a `build/`
subdirectory (ignored); deliberately retain a final PDF only when useful.

Execution logs, run notes, generated figures/tables, and executed notebook exports
belong in [runs/](../runs/README.md). Reference those generated assets from report
sources or deliberately copy selected publication assets here with a source note.
Canonical datasets remain in `data/processed/`.
