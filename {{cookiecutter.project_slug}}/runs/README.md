# Generated run artifacts

- Root: useful execution logs and concise run notes.
- `figures/`: generated plots and maps.
- `tables/`: generated summary tables.
- `notebooks/`: executed notebook copies and exports.

For substantial repeated work, group related artifacts under a descriptive run ID
or UTC timestamp here. A separate run directory is optional for simple exploration.
Contents are ignored except README files and placeholders. Canonical datasets belong
in `data/processed/`; authored LaTeX reports belong in [reports/](../reports/README.md).
See [run reporting](../guides/run-reporting.md) for logging and provenance.
